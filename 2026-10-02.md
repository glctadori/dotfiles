sudo reboot

## Via snaps

sudo systemctl disable --now snapd.socket snapd.service 2>/dev/null
sudo apt purge snapd
sudo apt autoremove --purge

Poi, per evitare che un futuro apt install te lo reinstalli come dipendenza/raccomandazione, aggiungerei un pin APT:
sudo tee /etc/apt/preferences.d/no-snapd.pref >/dev/null <<'EOF'
Package: snapd
Pin: release *
Pin-Priority: -10
EOF
